ℹ️ Catatan keamanan:
Halaman Admin Database digunakan untuk monitoring dan membaca informasi database. Operasi sensitif seperti mengubah atau menghapus data tidak dilakukan langsung dari browser.

Semua operasi database yang memiliki hak istimewa harus melalui backend dan pemeriksaan administrator.

Status database pada dashboard harus berasal dari pemeriksaan backend, bukan sekadar indikator frontend.
