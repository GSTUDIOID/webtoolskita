⚠ Catatan keamanan: Decoder ini hanya melakukan decoding payload JWT. Decoding JWT bukan berarti signature token telah diverifikasi. Jangan memasukkan token sensitif ke situs yang tidak kamu percayai.
JSON Web Token (JWT) biasanya terdiri dari tiga bagian:

Header berisi informasi seperti algoritma dan tipe token.
Payload berisi claims atau data token.
Signature digunakan untuk verifikasi integritas token.

Semua decoding dilakukan secara lokal di browser.
