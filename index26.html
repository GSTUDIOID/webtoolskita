Penyaluran Data

Kirim banyak file dari satu perangkat ke perangkat lain melalui koneksi P2P.

Pilih peran

📤 Pengirim

Pilih folder, buat kode koneksi, lalu tunggu penerima terhubung.

📥 Penerima

Masukkan kode dari pengirim, balas dengan kode koneksi, lalu terima file.

Koneksi menggunakan WebRTC. Kedua perangkat perlu bertukar kode secara manual. Kode tersebut berisi informasi koneksi, bukan isi file.

📥 Panel Penerima

Tempel kode pengirim. Setelah kode jawaban dibuat, kirim kembali kepada pengirim.

Progres penerimaan
Menunggu kode koneksi dari pengirim.
Belum menerima file.

File diterima terlebih dahulu di memori browser. Simpan hasil sebelum menutup atau memuat ulang halaman.

Cara penggunaan
1. Pengirim memilih folder lalu membuat kode koneksi.
2. Pengirim mengirim kode itu kepada penerima melalui kanal terpisah, misalnya chat.
3. Penerima menempel kode tersebut lalu membuat kode jawaban.
4. Penerima mengirim kode jawaban kembali kepada pengirim.
5. Pengirim menempel jawaban dan menghubungkan perangkat. Setelah tersambung, pengirim dapat mengirim file.

Gunakan hanya dengan orang yang kamu percaya. Kode koneksi bersifat sensitif; jangan membagikannya secara publik.
